# Compensation Catalog (SPARE) and Gifts

Use this to decide what can be offered as compensation. Offer it from the first contact and lead with what
you can do. Never offer an item that is not on these lists, and never name a device before stock is confirmed.
The current authoritative catalog is `assets/Spare Options.txt`; this file is a working copy of the same
lists. Before selecting anything, the customer's SPARE (budget) or order value must be known: **check ClickUp (and any attached PDF invoice) first**; if it is not present in ClickUp, ask the user for it (see SKILL.md §2, intake) and stay within the tier in §1.

## 0. OOS / discontinued override (check FIRST)

The list at the end of `assets/Spare Options.txt` ("OUT-OF-STOCK & DISCONTINUED") overrides every list in
this file (§1–§5). Before naming any compensation, spare, GBK gift or replacement, cross-check it against that
list. If the product is on it: never promise it, offer only the listed alternative, and confirm availability
with the agent before drafting. Never mention the stock status or the list itself to the customer.

| Situation | What to offer |
|---|---|
| Product is out of stock or discontinued **with** a listed alternative | Only that alternative (e.g. Rose & Rice Cleanser -> Turmeric Cleanser; AHA Cleansing & Exfoliating Foam -> Dor24K Turmeric Cleanser) |
| Product is out of stock or discontinued **without** an alternative | Do not offer it; pick another item from the same tier and concern, then confirm with the agent |
| **C.TOX** (any C.TOX product) | Multi-Vitamin Recovery 24H Moisturizer |
| **A.TOX** / A.TOX Eye Treatment (appears in the 1 Extra Atox tiers and the anti-aging gifts) | Always both pieces together: D'OR24K Advanced Eye Serum + D'OR24K Advanced Eye Cream |

Names in this file that match the list exactly (do not offer): Marvelous Signature, AHA Cleansing and
Exfoliating Foam. Names that are close but not identical to a list entry (for example D'OR24K MED SPA FOREVER
YOUNG SERUM COLLECTION vs. Dor24K Forever Young, Submarine MAX PRO+ vs. Submarine MAX PRO, Empire Ultimate
Collection Suitcase vs. Suitcase Empire Collection): confirm with the agent before offering.

## 1. What is approved, by order or SPARE value

| Order / SPARE value | Approved extra |
|---|---|
| $0 – $200 | 2 Daily creams / 1 ATOX |
| $201 – $500 | 4 Daily creams / 1 Mask + creams |
| $501 – $1,000 | 1 device / 6 Daily creams (MIX) |
| More than $1,000 | Package (Device + creams) |

- One extra product is always approved and is offered as the resolution *before* asking for approval.
- SPARE small or null → approval is needed. SPARE large → confirm on the same call.
- Sales up to $500 need no approval by default. See PENDING #2 in `business-rules.md` §8.
- Prefer creams and serums over devices unless the situation is extremely serious.

## 2. Gift for a rejected GBK (Give Back tax refund) benefit

Choose from the SPARE list according to the customer's SPARE value: creams or serums, not devices. State a
real reason (for example "Instructions"), never just "Gift".

Customers asking about the status of their tax refund contact Give Back directly:
phone **+1 (202) 838-4850** · email **care@givebackmytaxrefund.com**.
If the benefit was rejected, explain the cause where known (missing documentation, invalid card, and so on).
